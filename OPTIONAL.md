**Objetivo:** Crear una herramienta funcional de terminal para la gestión de tareas.

## 📌 ¿Con qué me quedo?

# Resumen de Aprendizajes

* **Listas (`list`):** Guardar, añadir (`append`) y borrar (`pop`) elementos en memoria.
* **Persistencia (`csv`):** Guardar y recuperar datos de un archivo local para no perder progreso.
* **Índices (0 vs 1):** Adaptar las posiciones de Python (base 0) a las del usuario (base 1).
* **Control del flujo:** Crear un menú interactivo continuo con `while` y funciones.
* **Validación:** Evitar cierres por errores con `try/except`.
